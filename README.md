Real Estate Market Dashboard – Power BI
Overview
An interactive Power BI dashboard that analyzes the Saudi real estate market and provides insights into transactions, property ownership, sales activity, and rental indicators.

Dashboard Pages
الرئيسية (Home)
نظرة عامة على السوق العقاري (Real Estate Market Overview)
تحليل صفقات البيع العقاري (Property Sales Analysis)
تحليل مؤشرات الإيجار (Rental Indicators Analysis)
تحليل الملاك حسب الجنس (Property Owners Analysis by Gender)
Key Features
Interactive filtering and drill-down analysis.
KPIs for transaction volume, transaction value, and total area.
Real estate sales trends and market performance insights.
Rental market indicators and comparisons.
Property ownership distribution analysis.
Professional Power BI visualizations and reporting.

Power BI

Project Objective
The purpose of this project is to transform real estate data into actionable insights that help users understand market trends, evaluate performance, and support data-driven decision-making.
